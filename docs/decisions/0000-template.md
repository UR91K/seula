# NNNN. Title in the imperative or as a statement

- **Status:** Accepted | Accepted (retrospective) | Reaffirmed | Incidental | Superseded by NNNN
- **Recognized:** when the problem was first understood, if that differs from when it was acted on
- **Decided:** date, with commit hash where one exists
- **Recorded:** date this file was written
- **Confidence:** decided now | remembered | reconstructed from git | inferred from code
- **Evidence:** commits, deleted files, code that corroborates the above — or "none exists by nature"

## Context

What was true that made this a question. The forces, the constraint, the thing that hurt.
Not the solution.

## Decision

What was chosen, stated plainly.

## Rejected alternatives

The load-bearing section. Each option considered, and why it lost — ideally in terms that
are still checkable. "Rejected because X" ages far better than "rejected because it felt
wrong", and it pre-empts the next person proposing X again.

## Consequences

What this bought, and what it cost. Include the costs honestly; an ADR that only lists
benefits is advocacy, not a record.

## Notes

Anything a future reader needs before reversing this. If reversal is cheap, say so — not
every decision deserves defending forever.
