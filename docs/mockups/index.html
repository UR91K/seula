Seula — frontend mockups

Static HTML, no build step. See README.md in this directory for how to run these and the ambiguities that were resolved while making them.

  • Projects
    Main view, richest state: batch toolbar, details panel, inline rename, plugin hover list, context menu, archived filter, import.
  • Projects — Tag manager
    Projects view with the tag manager modal open: create, rename, delete, usage counts.
  • Collections
    Grid of collection cards with a grid/list layout switcher.
  • Collection detail
    One collection opened: cover art, description, reorderable tracklist with a selection, consolidated task list.
  • Plugins
    Paginated list, search, format/vendor filters, tri-state installed toggle, hover tooltip with version/SDK details.
  • Samples
    Same shape as plugins: presence status, truncated path tooltip, extension filter, context menu with show-in-Explorer.
  • Stats
    Dashboard: overview cards, musical analytics, plugin/sample analytics, activity, insights, collection/tag analytics, task completion.
